# Prompt: resumo de mudanças e commit final

Use este prompt quando o usuário solicitou revisar alterações no projeto, confirmar se o README precisa ser atualizado e finalizar com commit e, se pedido, push.

## Objetivo

Executar a revisão final do projeto com foco em:
1. listar as mudanças realizadas de forma objetiva;
2. verificar se a documentação em README está alinhada com a implementação atual;
3. ajustar o README somente quando houver divergência real;
4. criar uma mensagem de commit clara, profissional e coerente com o que foi alterado;
5. executar commit e, quando solicitado, publicar no remoto.

## Fluxo de trabalho

1. Verifique o estado atual do repositório com git status e o histórico recente com git log.
2. Identifique os arquivos modificados e resuma as mudanças em linguagem técnica, curta e precisa.
3. Compare o que foi alterado com o conteúdo do README.
4. Se houver comportamento novo, correção funcional ou ajuste relevante não documentado, atualize o README.
5. Não altere o README sem necessidade; mantenha o texto alinhado ao projeto real.
6. Prepare uma mensagem de commit no padrão:
   - feat: ... para melhoria funcional ou nova funcionalidade
   - fix: ... para correção
   - docs: ... para documentação
7. Faça o commit com a mensagem escolhida.
8. Se o usuário pedir push, execute o push e confirme o resultado no terminal.
9. Antes de afirmar sucesso, valide o resultado com o output do git.

## Regras

- Foque em fatos observáveis do código e do git.
- Não invente alterações que não existam.
- Mantenha a mensagem de commit objetiva e representativa.
- Se o README já estiver consistente, não faça mudanças redundantes.
- Use linguagem técnica e profissional, em português ou inglês conforme o padrão do projeto.

## Exemplo de uso

- "Liste as mudanças realizadas, ajuste o README se necessário e faça o commit com a mensagem apropriada."
- "Resumo as alterações, atualiza a documentação e faz o commit final."
- "Revise o que mudou no projeto, confirme se o README está coerente e publique o commit."

## Saída esperada

Ao final, o assistente deve responder com:
- um resumo conciso das mudanças realizadas;
- indicação se o README foi atualizado ou se já estava consistente;
- mensagem do commit criada;
- confirmação do push, se solicitado.
